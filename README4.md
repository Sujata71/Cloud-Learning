## 🚀 Automated Infrastructure & Network Orchestration
* **Multi-Node Server Management:** Engineered an enterprise-level automation utility (`ssh_automation.py`) utilizing **Paramiko** to execute scripts across a distributed cluster topology.
* **Structured Inventory Imports (`csv`):** Standardized infrastructure node onboarding logs by reading server tracking configurations directly from `servers.csv`.
* **Network Exception Telemetry Handling:** Wrapped individual connection protocols inside robust error handling blocks to catch, log, and isolate unreachable or timed-out cloud instances gracefully.
* **Consolidated Data Logging (`pathlib`):** Formatted and aggregated systemic server responses across 20 nodes into a single, localized tracking artifact (`ssh_output.txt`).
