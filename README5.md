## 🖥️ System Telemetry & Infrastructure Monitoring
* **Hardware Resource Auditing:** Built a production-grade diagnostic framework (`system_health.py`) leveraging the **psutil** core engine.
* **Kernel & Memory Telemetry:** Automatically metrics live CPU runtime computations, RAM space allocations, and overall disk sector block capacities.
* **Automated Gateway Diagnostics:** Programmatically integrated shell subprocess ping commands to test real-time external network gateway health conditions.
* **JSON State Persistence:** Structured and exported raw system metrics into an automated, parseable data artifact (`health_report.json`).
